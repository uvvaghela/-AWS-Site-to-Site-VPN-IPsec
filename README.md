# -AWS-Site-to-Site-VPN-IPsec
Configured an AWS Site-to-Site VPN using Virtual Private Gateway, Customer Gateway and Libreswan/IPsec to establish connectivity between separate networks

## Project Overview
Implemented an AWS Site-to-Site VPN to establish secure connectivity between an AWS VPC and a simulated data-center network.

## Technologies Used
- AWS VPC
- Virtual Private Gateway
- Customer Gateway
- Site-to-Site VPN
- IPsec
- Libreswan
- EC2
- Route Tables
- Security Groups

## What I Implemented
- Created AWS VPC and private subnet
- Created a simulated data-center network
- Configured Virtual Private Gateway and Customer Gateway
- Created AWS Site-to-Site VPN connection
- Configured Libreswan/IPsec on the VPN server
- Configured routing between the networks
- Verified private-network connectivity through the VPN tunnel
